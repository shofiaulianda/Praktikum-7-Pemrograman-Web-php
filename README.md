## 📌 Deskripsi

Praktikum 7 membahas tentang pemrograman server-side menggunakan bahasa PHP (Hypertext Preprocessor). Praktikum ini bertujuan untuk memahami cara kerja PHP dalam memproses data pada sisi server serta menghubungkannya dengan halaman web.

## 🎯 Tujuan Praktikum

- Memahami perbedaan client-side dan server-side.
- Mengenal sintaks dasar PHP.
- Menggunakan variabel, tipe data, dan operator.
- Memahami percabangan dan perulangan.
- Menggunakan array dan function.
- Memproses form menggunakan metode GET dan POST.
- Melakukan validasi dan sanitasi input.
- Membuat aplikasi formulir data mahasiswa sederhana.

## 📚 Materi Praktikum

### 1. Latihan 1 - Menjalankan PHP
Menjalankan program PHP sederhana menggunakan server lokal dan menampilkan waktu server.

### 2. Latihan 2 - Variabel, Operator, dan Percabangan
Menghitung nilai akhir mahasiswa berdasarkan nilai tugas, UTS, dan UAS serta menentukan predikat.

### 3. Latihan 3 - Perulangan dan Array
Membuat daftar mahasiswa menggunakan array dan menampilkan data menggunakan perulangan foreach.

### 4. Latihan 4 - Membuat Function
Menggunakan function untuk menghitung harga setelah diskon dan luas persegi panjang.

### 5. Latihan 5 - Memproses Form dengan GET
Membuat form pencarian sederhana menggunakan metode GET.

### 6. Latihan 6 - Memproses Form dengan POST
Membuat form data mahasiswa yang menerima nama dan program studi menggunakan metode POST.

### 7. Latihan 7 - Pengolahan Data Sederhana
Membuat form transaksi barang untuk menghitung subtotal berdasarkan harga dan jumlah barang.

### 8. Mini Project - Aplikasi Formulir Data Mahasiswa
Membuat aplikasi formulir mahasiswa yang berisi nama, NIM, program studi, semester, dan email dengan validasi data menggunakan PHP.

## 🚀 Cara Menjalankan Program

1. Buka aplikasi XAMPP Control Panel.
2. Jalankan Apache dengan menekan tombol Start.
3. Simpan folder `Lab7Web_PHP` di dalam folder `htdocs`.
4. Buka folder proyek menggunakan Visual Studio Code.
5. Pastikan file PHP sudah disimpan.
6. Buka Google Chrome.
7. Masukkan alamat berikut untuk menjalankan latihan pertama:

```text
http://localhost/Lab7Web_PHP/latihan1.php
```

8. Ganti nama file pada alamat browser sesuai latihan yang ingin dijalankan.
